# Vikas Prajapati — Cybersecurity Portfolio

A modern, responsive React + Vite cybersecurity portfolio.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build for production

```bash
npm run build
npm run preview
```

## Add your resume

Copy your PDF into:

`public/Vikas_Prajapati_Resume.pdf`

The Resume button is already configured to download that file.

## Customize

Main profile and project content:
`src/main.jsx`

Visual styling:
`src/styles.css`

No backend or database is required.
